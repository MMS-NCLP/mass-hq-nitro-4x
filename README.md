## Governance

Three-role covenant governs all contributions:
- **Product stewardship** protects the business owner
- **Architectural stewardship** protects engineering integrity
- **Future stewardship** protects extensibility without premature inclusion

No implementation planning or source code generation shall begin until the Transition Guide has been completed and approved.
