# Dispatch V1 Product Realization Boundary

The accepted BP-000 through BP-015 and Commerce Operations services remain the domain authority. Product Realization adds a native Node HTTP delivery adapter, browser ES-module presentation, responsive navigation, role-derived route exposure, and provider-state rendering. It does not duplicate estimate, authorization, invoicing, scheduling, assignment, warranty, follow-up, reporting, security, or commerce decisions.

The browser bootstrap is explicitly a preview contract until deployment supplies authenticated sessions, persistence, Square, calendar, maps, and governed media-provider configuration. Preview values are labeled and never represented as live activity.

Operational Pulse V1 derives a restrained condition from explicit active, attention, overdue, and blocked counters. It is not Adaptive Ambient Dynamic Pulse V2 and makes no predictive or autonomous decision.
