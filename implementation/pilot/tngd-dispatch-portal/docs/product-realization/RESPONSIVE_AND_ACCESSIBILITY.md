# Responsive Field Experience and Accessibility

The delivery shell uses desktop, tablet, and phone layouts. Desktop preserves dense administration and operational context. Phone presentation replaces the rail with a five-action field navigation bar and prioritizes Today, Jobs, Inspection, Estimates, and Settings. The technician flywheel routes field states through navigation, arrival, diagnosis, inspection, estimate/authorization, invoice/payment, completion, and next destination.

Keyboard skip navigation, visible focusable controls, semantic landmarks, reduced-motion support, state text in addition to color, responsive tables, minimum practical touch targets, and light/dark color schemes are included. Deployment QA must still test supported physical devices, browsers, assistive technologies, and real provider content.
