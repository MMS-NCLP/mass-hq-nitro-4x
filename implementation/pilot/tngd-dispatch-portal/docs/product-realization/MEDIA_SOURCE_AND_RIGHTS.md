# Media Source, Rights, and Migration

The manifest uses stable asset IDs, provider-relative keys, checksums, tenant ownership, classifications, grades, approval states, internal/public eligibility, lineage, associations, and before/after relationships. A source registry converts those references into presentation URLs at runtime.

Changing from Google Drive to an external hard drive, object storage, or an API requires provider/root configuration rather than UI rewrites. Physical paths are prohibited from governed source keys.

Bundled approved inputs are the MASS HQ/Nitro 4x mark, TNGD primary mark, Dispatch system reference, and dark/light technician references. HQ garage-door, parts, motor, background, customer-portfolio, and repair-image collections are declared but unavailable until the provider can be inventoried and rights metadata verified. Their UI slots use intentional fallbacks and do not fabricate media.
