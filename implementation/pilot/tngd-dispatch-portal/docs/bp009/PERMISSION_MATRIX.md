# BP-009 Permission Matrix

| Role | Authority |
|---|---|
| Dispatch Administrator | Create and edit drafts, finalize, revise, record referenced outcomes |
| Manager / Tenant Administrator | Same governed operational authority and read history |
| Technician | No repair/estimate record authority |
| Customer | No internal draft access; BP-010 owns authorization evidence |
| Executive | Governed summaries only |

All operations use BP-001 tenant checks and the shared audit chain.
