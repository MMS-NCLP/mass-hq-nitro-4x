# BP-010 Permission Matrix

| Actor | Authority |
|---|---|
| Dispatch Administrator / Manager / Tenant Administrator | Prepare requests, amendments, and governed reads |
| Customer or authorized adult | Decide only through scoped transaction access with adult acknowledgment |
| Technician / Employee / AI | Cannot authorize for the customer |
| Auditor | Governed read only where separately granted |

Recommendation, presentation, and authorization remain separate authorities.
