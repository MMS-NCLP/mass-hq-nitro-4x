# APP-014 to APP-015 Transition Brief

APP-015 may provide governed plugin and capability extension contracts. It must consume APP-014 advisory interfaces without duplicating sessions, memory, decisions, agents, communications, execution intelligence, discovery, executive awareness, assurance, learning, governance reasoning, context assembly, or evaluation governance.

Every APP-015 extension must preserve tenant isolation, source ownership, human approval, ENG-009 orchestration authority, gateway boundaries, event traceability, version compatibility, revocation, and auditability. APP-015 cannot treat APP-014 closure candidacy as freeze authority.
